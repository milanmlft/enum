## Overview

`enum` is an R package providing immutable, validated enumerations built on the **S7** object system (the only import). `Enum(NAME = value, ...)` returns an `Enum_class` S7 object.

## Architecture

- `R/Enum-class.R`: the `Enum_class` S7 class (properties `values` as a list and `enum_names` as a character vector), its `validator`, and the `Enum()` constructor. It also holds the `print`/`str`/`format`/`==`/`!=` methods, `is.enum()`, and the `%||%` helper. Validation is split in two layers: `Enum()` checks that every argument is named and that names are unique, and throws friendly errors. The class `validator` re-checks the invariants (equal lengths, no duplicate names, no empty or NA names) for any direct construction.
- `R/accessors.R`: `$`, `$<-`, `[[` and `names` methods. `$<-` always errors, which is how immutability is enforced. Unknown names error rather than returning `NULL`.
- `R/coercion.R`: `as.list` method.
- `R/zzz.R`: `.onLoad` calls `S7::methods_register()`, which is required for S7 methods on base generics (`print`, `format`, `$`, ...) to work. Keep it when adding methods for external generics.
- Errors are raised with `stop(..., call. = FALSE)`.
- Tests live in `tests/testthat/` (testthat 3e), one file per area (`test-Enum.R`, `test-accessors.R`).
